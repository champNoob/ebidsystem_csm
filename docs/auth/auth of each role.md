client:
- 查看个人信息
- 查看个人订单
- 创建买单
- 取消自己的 pending / partial 买单

seller:
- 查看个人信息
- 查看个人订单
- 创建卖单
- 取消自己的 pending / partial 卖单

trader:
- 查看个人信息
- 查看自己经手订单
- 创建买单
- 创建卖单
- 取消自己经手订单

sales:
- 查看被分配客户的基础信息
- 创建订单草稿
- 查看草稿状态
- 不可直接提交正式订单
- 不可直接进入撮合引擎

admin:
- 查看系统看板
- 查看所有用户
- 查看所有订单
- 查看所有成交
- 管理用户状态和角色
- 不可提交正式订单
- 原则上不直接修改撮合结果
